# ScreenPulse - Component Documentation

Welcome to the ScreenPulse component library documentation.

## What is ScreenPulse?

ScreenPulse is a modern web application for discovering and managing movies, series, and games. Built with Angular and powered by the OMDB API, it provides a seamless experience for searching media content, managing favorites, and exploring entertainment collections.

## 🎯 Key Features

- **Smart Search**: Search movies, series, and games by title, type, and year
- **Favorites Management**: Save and organize your favorite media items
- **Detailed Information**: View comprehensive details including ratings, cast, and trailers
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Material Design**: Built with Angular Material components

## 📖 Component Architecture

### Smart Components (Containers)
Manage state, API calls, and business logic. Located in feature modules:

- **SearchPage** (`/features/search`)
  - Orchestrates search flow with OmdbService
  - Manages search state (filters, results, pagination)
  - Handles user interactions (submit, pagination, favorites)

- **FavoritesPage** (`/features/favorites`)
  - Manages user's favorites collection
  - CRUD operations via FavoritesService
  - Sorting and filtering logic

- **AuthPage** (`/features/auth`)
  - Switches between login and register modes
  - Authentication flow with AuthService
  - Route navigation after successful auth

### Presentational Components (Dumb)
Receive data via `@Input()`, emit events via `@Output()`. No direct service dependencies.

#### Shared Components
Reusable across multiple features:
- **EmptyState** - Generic empty state display
- **LoadingSpinner** - Loading feedback indicator
- **MediaItemDialog** - Media details modal
- **TrailerDialog** - YouTube trailer player

#### Feature-Specific Components
Used within a single feature module:

**Search Page Components:**
- **SearchBar** - Form inputs for search filters
- **SearchCover** - Hero section banner
- **Carousel** - Featured media slider
- **MediaItemResultsTable** - Results table with pagination

**Favorites Page Components:**
- **FavoritesCard** - Individual favorite card display
- **SortingControls** - Search input and sort dropdown

**Auth Page Components:**
- **AuthForm** - Login/register form (mode-switched)

### Layout Components
Global components rendered in AppComponent:
- **Navbar** - Top navigation (app-wide)
- **Footer** - Site footer (app-wide)

## 🔧 Key Services

### OmdbService
External API integration for fetching movie, series, and game data from OMDB API.

### FavoritesService
Backend API integration for managing user favorites (add, delete, update, list).

### DialogService
Lazy-loaded dialog management for media details and YouTube trailers.

### AuthService
Authentication state management using sessionStorage tokens.

## 🎨 Design Principles

- **Mobile-First**: Responsive design starting from 320px
- **Accessibility**: WCAG 2.1 AA compliance with keyboard navigation
- **Performance**: Lazy loading, optimized builds, efficient state management
- **Consistency**: Angular Material design language throughout
